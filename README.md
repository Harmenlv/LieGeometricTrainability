## Overview

This repository provides the official implementation for the paper:

> **Lie-Geometric Trainability of Quantum Dynamical Systems: Avoiding Barren Plateaus via Low-Dimensional Lie Subalgebras**

The project develops a Lie-geometric framework for understanding trainability in quantum neural networks (QNNs) through the algebraic and representation-theoretic structure of their generator spaces.

The main conclusion is that:

* QNNs restricted to polynomial-dimensional Lie subalgebras avoid barren plateaus by construction.
* Full-Hilbert parameterizations exhibit exponentially vanishing gradient variance.
* Barren plateaus arise as a geometric concentration phenomenon induced by high-dimensional Lie-group actions.

The repository includes:

* collective-spin Lie-QNN benchmarks
* full-Hilbert hardware-efficient QNN baselines
* gradient variance scaling experiments
* initial residual scaling verification
* appendix-style finite-size sanity checks
* reproducible numerical protocols

# Theoretical Background

The framework studies the relationship between:

```text
Polynomial Lie subalgebra
        ↓
Polynomial orbit dimension
        ↓
No geometric concentration
        ↓
Avoid barren plateaus
```

In contrast, exponentially large unitary orbits generated by the full Lie algebra:

[
\mathfrak{su}(2^n)
]

lead to gradient concentration and exponentially vanishing trainability signals.

# Collective-Spin Lie-QNN Ansatz

The revised Lie-restricted benchmark uses the collective-spin ansatz

[
U_{\rm Lie}(\theta)
===================

\prod_{\ell=1}^{L}
e^{-i\alpha_\ell J_x}
e^{-i\beta_\ell J_z^2/n}
e^{-i\gamma_\ell J_y},
]

where

[
J_x=\frac12\sum_i X_i,\quad
J_y=\frac12\sum_i Y_i,\quad
J_z=\frac12\sum_i Z_i.
]

The dynamics remain inside the permutation-symmetric Dicke sector:

[
\dim(V_{n/2}) = n+1,
]

which provides a polynomial-dimensional invariant representation space compatible with the trainability theorem developed in the paper.
